**Notes:**

Okta Workflows has various `connectors`. These connectors help establish connections/integrations with either an external SaaS service or a service we host on our environment. These connectors help us send/push data to the connector system or retrieve/pull data from it. Connectors that are out of box like Amazon, Google, Salesforce will ask for details to create and establish the connection. For Example: 
- For Amazon S3 the connector will need an Account ID, External ID, and Role ARN (Amazon Resource Name).
- For API Connectors we will need the Authentication type and then the details for authenticating. If it is Custom then it will give the Header Name and Header Value.
We would need to use the `connection builder` for connections which do not have a native integration or template for the connection within Okta.
